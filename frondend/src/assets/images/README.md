# Menu Category Images

This directory contains placeholder images for the menu categories in the customer menu page.

## Required Images:
- breakfast.jpg - Breakfast items like pancakes, eggs, etc.
- coffees.jpg - Coffee and other beverages
- burgers.jpg - Burger items
- desserts.jpg - Desserts like cakes, ice cream, etc.
- pastas.jpg - Pasta dishes
- soups.jpg - Soup dishes

Please replace these placeholder references with actual image files. The images should be:
- High quality (at least 500x500px)
- Properly cropped to focus on the food
- Optimized for web (compressed JPG or WebP format)
- Consistent in style and lighting

For best results, use images that match the restaurant's actual menu items.
